# 三晚助手 · 私人维护记录

英雄联盟国服账号维护记录工具。网页入口使用 GitHub Pages，私人记录由 Cloudflare Worker 和 D1 保存；独立 Windows 软件及完整桌面源码在本仓库 Releases 中提供，基于 LeagueAkari MIT 开源代码修改。

## 登录与记录

- 先注册并登录三晚助手账号。用户名和密码不设长度或字符格式限制，不能为空，用户名不能重复；支持中文用户名和一位密码。用户名忽略首尾空格及英文字母大小写，密码保持原样。当前没有自助找回密码，请保存好账号密码。
- 默认勾选「记住登录」，登录状态永久有效，主动退出时撤销并清除；不勾选则只保留当前会话（最长 2 小时）。网页保存登录凭据，桌面版使用 Windows 加密存储，均不保存明文密码。旧版会话不会自动延长，请在新版首次登录时勾选。
- 每个登录账号只能查看和修改自己的维护记录，同一账号可在其他电脑登录。服务器校验所有读写权限。微信登录需完成开放平台申请和审核，目前未开通。
- 旧版共享记录保留并停止公开，需要管理员核实归属后定向迁移，不会自动分给第一个注册者。
- 新增时填写游戏 ID、编号、下拉选择大区和剩余天数；自动查询单双排段位、胜点并记录精确录入时刻。
- 列表按剩余天数升序，只有 0 天提醒。查询到人工基准后的单双排每局加一天，23:55（北京时间）扣一天，大师及以上最多 14 天、钻石最多 28 天；重复查询不重复累加。结果为估算，以游戏客户端为准。
- 查询游戏资料需要本机登录英雄联盟并运行查询服务。推荐使用 Releases 中的桌面软件；该版本没有无人值守云端查询。

部署与数据库迁移见 `worker/README.md`，认证与私有化迁移见 `worker/AUTH.md`。`worker/dist/worker.js` 是可部署的完整单文件。服务器需配置 Secret `AUTH_PASSWORD_PEPPER`，不要把密钥写入源码。前端服务地址在 `config.js`。

主软件战绩页显示当前段位和胜点总分，每局加减分功能已移除。维护界面已修正深色主题文字对比度，并移除「导出备份」按钮。详细使用说明与真实验证范围见桌面源码包的 `README-桌面分支.md`。
